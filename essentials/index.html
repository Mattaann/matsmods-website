Mat's Essentials Mod

View the current time, coordinates, crop growth, and targeted blocks directly on your screen without needing additional items.

Enable practical features such as Tree Felling, Fast Leaf Decay, Right-Click Harvest, graves, protected farmland, and safer mob interactions. Every feature can be enabled or disabled individually, allowing you to customize the mod for your preferred playstyle.

Lightweight, organized and easy to use.

How to use: Type /matsessentials in the chat to open the settings menu.

Note: All UI features are enabled by default, while all Game Mechanics features are disabled until you choose to enable them.

Fabric API Required
