Kingdom Quests beta

The kingdom is under constant threat.

Monsters are growing stronger, dangerous creatures roam beyond the castle walls and the villagers need your help.

Complete quests, deliver supplies, explore distant lands, hunt powerful Kingdom Drakes and help strengthen the realm ruled by the great King Martin.

Every completed quest brings the kingdom closer to safety. Rise through the ranks, earn valuable rewards and prepare yourself for the King's final mission.

Required Dependency

Fabric API Required

Fabric API is required for Kingdom Quests to work correctly. Download both files and place them in your Minecraft mods folder.

Download Kingdom Quests 26.2 Download Fabric API

Make sure you download the Fabric API version that matches your selected Minecraft version.
